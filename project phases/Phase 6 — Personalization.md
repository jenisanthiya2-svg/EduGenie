# PHASE 6 — PERSONALIZATION

## Objective

Make EduGenie AI provide learning content according to the student's learning needs.

## Step 1 — Collect Student Input

The system receives:

```text
Topic
Question
Learning Goal
```

## Step 2 — Analyze Input

The AI identifies what the student needs.

Example:

```text
Topic: Python
Goal: Beginner
```

The system should provide beginner-level content.

---

## Step 3 — Personalized Explanation

Instead of giving a complex explanation, the AI should provide:

```text
Simple Definition
       ↓
Basic Explanation
       ↓
Example
       ↓
Practice
```

---

## Step 4 — Personalized Learning Path

Example:

```text
Python Basics
      ↓
Variables
      ↓
Data Types
      ↓
Conditions
      ↓
Loops
      ↓
Functions
      ↓
Mini Project
```

## Step 5 — Practice Recommendation

The system can recommend:

* Quiz
* Practice questions
* Revision
* Mini project

## Phase 6 Output

EduGenie should behave as a personalized learning assistant rather than only a basic chatbot.
